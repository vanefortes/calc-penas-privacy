CALCULADORA PENAL
Política de Privacidade
Última atualização: junho de 2026

Resumo simples: este aplicativo não coleta, não armazena e não compartilha seus dados em servidores externos. Todas as informações inseridas ficam salvas exclusivamente no seu dispositivo e sob seu controle.

1. Quem somos

A Calculadora Penal é um aplicativo desenvolvido por V Forttes Software Engineer, destinado a profissionais do direito que necessitam realizar cálculos de penas privativas de liberdade, projeções de datas e análise de períodos entre datas.

Para dúvidas sobre esta política, entre em contato pelo e-mail support@vforttes.com.

2. Quais dados o aplicativo utiliza

Dados de perfil

Nome completo, número da OAB, e-mail e foto de perfil — informados voluntariamente pelo usuário durante o primeiro acesso.

Dados de cálculo

Períodos de pena, datas e resultados gerados pelo usuário, armazenados no histórico do aplicativo.

Login com Google (opcional)

Caso o usuário opte por preencher o perfil com sua conta Google, o aplicativo importa nome, e-mail e foto de perfil fornecidos pelo Google. Nenhuma outra informação da conta Google é acessada.

Biometria

O aplicativo pode utilizar Face ID ou Touch ID para desbloquear o acesso. Os dados biométricos são processados exclusivamente pelo sistema operacional do dispositivo e nunca são acessados ou armazenados pelo aplicativo.

3. Como os dados são armazenados

100% local

Todos os dados são salvos exclusivamente no armazenamento interno do seu dispositivo, utilizando os mecanismos nativos e seguros de armazenamento local do sistema operacional (iOS ou Android). Nenhum dado é enviado para servidores externos, nuvem ou terceiros.

Os dados permanecem no dispositivo até que o usuário os apague manualmente pelo próprio aplicativo ou desinstale o app.

4. Compartilhamento de dados

Este aplicativo não compartilha, não vende e não transmite quaisquer dados do usuário para terceiros, parceiros, anunciantes ou serviços externos.

O aplicativo não possui integração com serviços de análise (analytics), publicidade ou rastreamento.

5. Permissões solicitadas

  • Biometria (Face ID / Touch ID / impressão digital): para autenticação local ao abrir o aplicativo, se ativada pelo usuário.
  • Fotos: para permitir que o usuário selecione uma foto de perfil a partir da galeria do dispositivo. A imagem é salva apenas localmente.
  • Internet: utilizada exclusivamente para o login opcional com Google. Não é utilizada para enviar dados do usuário.
  • Armazenamento: para salvar e exportar relatórios em PDF gerados pelo usuário.

Nenhuma permissão é solicitada além das estritamente necessárias para o funcionamento das funcionalidades descritas. Em dispositivos iOS e Android, essas permissões só são solicitadas no momento em que a funcionalidade correspondente é utilizada pela primeira vez.

6. PDFs gerados

Os relatórios em PDF gerados pelo aplicativo contêm os dados de cálculo e, opcionalmente, o nome e OAB do usuário. Esses arquivos são criados localmente e compartilhados apenas quando o próprio usuário decide enviá-los (por e-mail, WhatsApp, etc.). O aplicativo não acessa, armazena ou transmite os PDFs gerados.

7. Menores de idade

Este aplicativo é destinado exclusivamente a profissionais do direito maiores de 18 anos. Não coletamos intencionalmente informações de menores de idade.

8. Seus direitos

Como todos os dados ficam no seu próprio dispositivo, você tem controle total sobre eles. Você pode:

  • Editar seu perfil a qualquer momento pelo menu de configurações do app.
  • Limpar o histórico de cálculos pela tela de histórico.
  • Excluir, em uma única ação, sua conta e todos os dados salvos (perfil, histórico, preferências e sessão do Google), em Configurações → Zona de risco → Excluir conta e dados.
  • Remover todos os dados desinstalando o aplicativo.

9. Segurança

Os dados são armazenados nos mecanismos de armazenamento seguro do Android. O acesso ao aplicativo pode ser protegido por autenticação biométrica, conforme configurado pelo usuário. Recomendamos manter o sistema operacional do dispositivo sempre atualizado.

10. Alterações nesta política

Caso esta política seja alterada, a data de "última atualização" no topo deste documento será modificada. Alterações significativas serão comunicadas ao usuário por meio de aviso no próprio aplicativo.

11. Contato

Para dúvidas, solicitações ou sugestões relacionadas a esta política de privacidade, entre em contato pelo e-mail support@vforttes.com.
